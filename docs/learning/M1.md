# M1: the data recorder

## What was built, and why this design

A 24/7 process that polls BSE and NSE for filings, prices, price bands and
instrument lists, and stores everything **point-in-time**. Three choices carry
the design:

- **Raw first.** Every response is saved, byte for byte, in a
  content-addressed store (file name = SHA-256 of the bytes) *before* it is
  parsed. Parsers are pure functions with a version number. When a parser
  turns out wrong (it did, several times), you fix it and run
  `gats reparse`; nothing has to be downloaded again, and nothing is lost.
- **Two clocks per row.** `event_ts` is when the world says it happened
  (exchange dissemination); `available_at` is when *this system* could have
  known it. Research only ever filters on `available_at`.
- **Idempotent, resumable jobs.** Every write is an insert-or-ignore or
  upsert on a natural key, so a crash, a re-run or an overlapping backfill
  never duplicates data. Backfills record per-day completeness, so a
  half-finished day is retried and a finished one skipped.

## Key concepts

- **Look-ahead bias:** using information in a simulation before it existed.
  `available_at` plus the `AsOf` reader make it structurally hard.
- **Politeness and backoff:** one request per host per interval, exponential
  backoff with jitter, `Retry-After` honoured. Aggressive clients get blocked.
- **Verify, don't assume:** the first version was written without network
  access; real probes then found BSE serving past days in a different shape
  (no page count), which had silently truncated backfills. Tests on trimmed
  real samples (`tests/fixtures/real/`) keep the parsers honest.

## What could go wrong

- The laptop sleeps: data stops. `gats status`/`doctor` say so in plain words;
  the reconcile job heals the last 7 days.
- An exchange changes a format: the parser fails loudly, the bad payload is
  kept (`gats inspect-bad`), and the fix is a reparse away.
- Content addressing has a subtle edge: identical bytes are stored once, under
  the *first* kind that saved them (a probe), which once hid rows from a
  reparse. Selection now follows the rows' references, not the kind label.
